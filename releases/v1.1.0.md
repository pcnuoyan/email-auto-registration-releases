# v1.1.0

发布日期：2026-09-09

## 版本说明

本版本增强管理后台收件箱的查询能力，并改进 Windows 环境下的版本维护与验证流程。

## 新增功能

- 支持按发件人邮箱进行不区分大小写的模糊筛选。
- 支持筛选全部邮件、仅未读或仅已读邮件。
- 支持筛选含验证码或不含验证码的邮件。
- 支持查看最近 24 小时、最近 7 天或最近 30 天收到的邮件。
- 主题、别名邮箱、发件人、阅读状态、验证码和收件时间条件可组合使用。

## 维护改进

- 修复 Windows PowerShell 5.1 下升版脚本和完整验证脚本的成功状态判断。
- 收紧 npm 锁文件版本替换范围，避免升版时修改第三方依赖版本。
- 隔离宿主机通用 `DEBUG` 环境变量对后端验证的影响。

## 验证

- 后端完整测试：691 passed、38 skipped，覆盖率 82.13%。
- 前端 TypeScript 检查与生产构建通过。
- 版本一致性、Ruff、mypy、Alembic head 和敏感信息扫描通过。

## 部署

本版本采用 Docker Compose 手动更新，不支持从管理页面自动替换运行中的容器。
