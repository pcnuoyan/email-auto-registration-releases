# v1.0.0

发布日期：2026-09-09

## 版本说明

这是 iCloud HME 管理平台的首个正式版本，面向个人自用、单管理员场景。

## 主要功能

- 管理本人授权的 iCloud+ 母账户与 Hide My Email 别名。
- 支持 CK 导入、校验、对账、暂停、恢复和归档。
- 支持 HME 别名批量生成、额度管理、冷却调度、失败恢复和幂等控制。
- 支持别名库存查询、分配、停用、回收、导出和公开访问链接。
- 支持 IMAP Hybrid 自动同步、UID 增量收件、验证码提取和新邮件通知。
- 支持邮件 HTML 白名单净化、正文保留期限和敏感数据清理。
- 提供总览、账户、活动、库存、收件箱、邮件详情、接入指南和系统设置页面。

## 安全

- CK、IMAP 密码和验证码使用 AES-256-GCM 加密存储。
- 公开访问令牌仅保存哈希。
- 日志、错误响应和审计记录不保存凭据、验证码或完整邮件正文。
- 邮件 HTML 在白名单净化后通过 sandbox iframe 展示。

## 部署

本版本采用 Docker Compose 手动更新，不支持从管理页面自动替换运行中的容器。
