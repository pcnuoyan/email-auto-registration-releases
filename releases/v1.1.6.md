# v1.1.6

发布日期：2026-09-13

## 版本说明

本版本完成代理管理闭环：统一管理单个代理地址、订阅节点和高级代理配置，并补齐加密订阅同步、节点选择、Mihomo 独立运行配置、真实出口测试与逻辑删除。

## 新增

- 支持加密保存 Clash/Mihomo 订阅、异步同步节点、安全筛选地区和选择当前节点。
- 每条订阅使用独立 Mihomo Provider；选择和测试时物化运行配置，确认节点存在后才提交切换。
- 代理主列表统一展示单地址、高级代理和订阅当前节点，并提供详情、同步历史、编辑、测试和全局地址脱敏。
- 高级配置支持住宅、旋转和提取 API 代理，以及连接异常、冷却、临期、同步失败和待选节点提醒。

## 优化

- 过滤订阅中的剩余流量、到期、重置、官网和更新提示等非代理节点。
- 对安全节点元数据集合相同的订阅显示重复内容提示，不自动停用、删除或合并。
- 手工代理地址不再使用私网或本地地址白名单；地址可保存，实际可用性由连接测试判断。
- 移除代理来源模型，代理记录直接承载类型、地址、非敏感配置和加密凭据。
- 移除代理归档功能，统一使用不可恢复的逻辑删除；存在有效活动租约或同步任务时禁止删除，历史记录继续保留。

## 安全

- 订阅 URL 使用 AES-256-GCM 或 Secret Manager 引用保存，不进入 API、日志、审计或浏览器状态。
- 订阅抓取执行 HTTPS、DNS/IP SSRF、超时、2 MiB 响应和 2,000 节点限制，禁止环境代理和重定向改变安全边界。
- 节点凭据只写入受限 Mihomo 运行目录；加载或切换失败时恢复原配置和数据库选择。
- 出口 IP 只来自代理或选中节点的真实连接测试，并统一受地址脱敏开关控制。

## 数据库迁移

- 新增迁移 `20260913_0018`～`20260913_0022`，建立订阅、节点和同步任务数据模型，补充节点主机、真实出口、内容指纹及逻辑删除字段。
- 升级前应先备份 PostgreSQL，随后执行 `alembic upgrade head`；升级后的唯一 head 为 `20260913_0022`。
- 旧代理归档记录会自动转换为逻辑删除；删除后的历史健康、租约、节点、同步任务和审计不会被物理移除。

## 验证

- 后端完整测试：946 passed、40 skipped，覆盖率 80.04%。
- Ruff、mypy 152 个源文件、Alembic head、代理订阅契约和敏感信息扫描通过。
- 前端版本、登录、导航和代理管理回归，以及 TypeScript 检查和 Vite 生产构建通过。

## 部署

本版本引入 Mihomo sidecar 运行配置。生产环境在启用订阅节点测试前，必须配置内部 Controller、强随机密钥、共享且权限受限的运行目录和本地代理出口；未完成 sidecar 配置时应保持 Mihomo Mock 模式。升级与迁移步骤见源码仓库部署文档。
